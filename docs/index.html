方法論：考慮了哪些因素？

  • Elo 戰力評等 — 逐場更新，內建勝分差修正（大勝/大敗調整幅度更大）、主場優勢加成、季後賽權重提升、賽季間回歸平均值。
  • 休息天數 / 短週賽 / 待命週 — 主客兩隊的休息天數差，反映短週四夜賽的疲勞劣勢與待命週後的體能優勢。
  • 先發QB異動 — 追蹤每隊最近已知的先發QB，偵測是否臨時更換（歷史上單一最大的比賽結果擺動因子之一）。
  • 天氣與場地 — 戶外比賽的低溫、強風條件，室內/圓頂球場則不受影響。
  • 分區內對戰 / 季後賽情境 — 分區對手較熟悉彼此、季後賽強度與變異度不同。
  • 市場賠率校驗 — 使用真實歷史 Vegas 收盤盤口（分差與美式賠率）作為獨立比較基準，而非模型輸入，確保評估公正透明。

本工具不包含即時傷兵名單細節、比賽當下天氣預報（僅使用比賽日已知資訊）、教練臨場調度等更細緻的訊號； 這是一套方法公開、可回測、誠實揭露準確度的統計模型，適合研究與教育用途，不構成博弈建議。

手動更新資料

本網站每週二台灣時間晚上 6 點（Monday Night Football 結束後）會自動重新抓取最新賽果／賽程／ 盤口並更新，不需要手動操作。若想立即更新，有兩種方式：

方式一（最簡單）：直接前往 GitHub Actions 頁面， 點右上角「Run workflow」。

方式二：在下方輸入一組僅授權此 repo「Actions: Read and write」權限的 GitHub 權杖（fine-grained personal access token），直接在這個頁面按鈕觸發。權杖只會存在 你自己瀏覽器的 localStorage，不會送到除了 GitHub API 以外的任何地方，但 仍建議使用最小權限的權杖，並在公用電腦上使用後按「清除已儲存的權杖」。
